# Cálculo de Precio de Compra con Funciones

Programa desarrollado para la tarea de **Programación Básica** que implementa el uso de funciones con parámetros y retorno de valores en Python.

## Descripción del Problema
Resuelve un caso de la vida real: calcular el costo total de una compra en un establecimiento comercial, aplicando de manera automática un porcentaje de descuento y sumando el impuesto correspondiente (IVA).

## Características del Código
* **Definición de función:** `def calcular_total_compra(...)`
* **Parámetros de entrada:** Precio unitario, cantidad, descuento e impuesto.
* **Retorno de valores:** Uso de la palabra clave `return` para devolver el cálculo final.
* **Llamada y salida:** Ejecución de la función y presentación formateada en consola.
